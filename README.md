# Air Alert Map

Open-source Android застосунок для відображення повітряних загроз та офіційних тривог.

## Сайт

https://fan-world-me.github.io/airalertmap/

На сайті кнопка **«Завантажити актуальну версію»** веде на `Releases → latest`, тому після публікації нового релізу посилання автоматично відкриє найновішу версію.

## GitHub

- [Код проєкту](https://github.com/fan-world-me/airalertmap)
- [Релізи](https://github.com/fan-world-me/airalertmap/releases)
- [Issues](https://github.com/fan-world-me/airalertmap/issues)

## GitHub Pages

Сайт знаходиться в `docs/` і деплоїться через GitHub Actions workflow `.github/workflows/pages.yml`.

Після першого push відкрий **Settings → Pages** і перевір, що для репозиторію дозволено GitHub Pages / GitHub Actions як джерело деплою.

## Дані

Дані повітряних загроз: [NEPTUN](https://neptun.in.ua/). Карта: [OpenStreetMap](https://www.openstreetmap.org/).

> Застосунок не є єдиним джерелом інформації про безпеку. Під час тривоги користуйтеся офіційними сповіщеннями та вказівками місцевої влади.
